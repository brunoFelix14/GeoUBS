Sobre o GeoUBS

Sistema acadêmico para localizar e consultar Unidades Básicas de Saúde de Três Lagoas/MS.

O projeto utiliza HTML, CSS, JavaScript, Leaflet, Python/Flask e PostgreSQL. Os dados podem ser mantidos pelo painel administrativo.
